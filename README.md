## 👨‍💻 About Me

I'm a **DevOps / Platform Engineer** based in Ho Chi Minh City, Vietnam, with hands-on experience operating production systems on **Kubernetes** and **Docker Swarm**, supported by a background in software development.

I focus on building and operating cloud-native infrastructure, improving delivery workflows through **GitOps and CI/CD**, strengthening Kubernetes security, and making systems observable and reliable.

- ☸️ Kubernetes platform operations, troubleshooting, and workload orchestration
- 🚀 GitOps, CI/CD automation, and multi-environment release management
- 🏗️ Internal Developer Platform (IDP) and self-service deployment workflows
- 🔐 Kubernetes security hardening, vulnerability scanning, and secrets management
- 📈 Monitoring, observability, incident response, and root cause analysis
- ☁️ AWS infrastructure and containerized application operations
